# PIMEX

## Physics-Informed Modular Digital Twin for Real-Time Prediction in Mechanized Tunnelling

PIMEX is a research project combining physical modelling and machine learning to support real-time prediction and decision-making in mechanized tunnelling. Its modular framework aims to represent interacting excavation processes while working with limited and noisy observations.

This repository is the central project hub. Separate repositories for individual models will be linked here as they become available.

## Research focus

The project brings physics-informed learning and spatiotemporal modelling together to study ground deformation, pore-pressure changes, and machine–ground interactions. The wider framework considers approaches such as PINNs, ConvLSTMs, and graph neural networks, with the aim of supporting safer and more efficient underground construction.
